# Minux PowerToys

A small, growing collection of Windows power-user utilities. The code lives in
[`minux-powertoys/`](minux-powertoys/).

The first tool is **KeyboardMe** — type a block of text into any focused window
(including Remote Desktop / VM consoles where paste is blocked) at a human pace.
It will never type faster than a person can.

See [`minux-powertoys/README.md`](minux-powertoys/README.md) to install and run.
